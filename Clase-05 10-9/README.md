## 📌 Cosas importantes a tener en cuenta

* **Cómo abrir el proyecto:** para que el `fetch('./productos.json')` del ejercicio 7 funcione, `index.html` tiene que abrirse con un servidor local (por ejemplo, la extensión "Live Server" de VS Code) y no con doble clic directo, porque algunos navegadores bloquean el `fetch` a archivos locales por política de seguridad (`file://`).
* **Respuestas a las preguntas de reflexión (Ejercicios 1 y 2):** las dejé como comentarios dentro de `app.js`.
* **Estructura de archivos:**
  * `index.html` → estructura visual + estilos embebidos.
  * `app.js` → toda la lógica de los 10 ejercicios.
  * `productos.json` → datos locales usados en el Ejercicio 7.
* **No usé nada fuera de lo visto en clase**
