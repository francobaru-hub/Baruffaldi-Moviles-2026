# Herramientas utilizadas

Para realizar los ejercicios y el desafío de **Peaje Inteligente (Telepase)** utilicé diferentes herramientas y recursos de aprendizaje.

## 1. Contenido teórico del repositorio

Utilicé el **contenido teórico del repositorio de la materia** como material de consulta. Allí se encuentran los conceptos necesarios para resolver los ejercicios, como:

* Variables.
* Condicionales.
* Operadores lógicos.
* Bucles.
* Funciones.
* Métodos y propiedades básicas de JavaScript.

El contenido del repositorio fue la base para comprender los temas y aplicarlos en los ejercicios.

## 2. ChatGPT

Utilicé **ChatGPT** para:

* Comprender las consignas de los ejercicios.
* Resolver dudas sobre JavaScript.
* Revisar la lógica utilizada en las funciones.
* Entender errores y conceptos que no tenía claros.
* Corregir errores
* Obtener explicaciones sencillas sobre el funcionamiento del código.
* Hacer el READMe.md

ChatGPT fue utilizado como apoyo al aprendizaje y no como reemplazo del contenido teórico de la materia.

## 3. RunJS

Utilicé **RunJS** para ejecutar los archivos JavaScript y probar que las funciones funcionaran correctamente.

Con esta herramienta pude:

* Ejecutar las funciones.
* Probar diferentes casos.
* Comparar los resultados obtenidos con los resultados esperados.
* Detectar y corregir errores en el código.

Esto me permitió comprobar el funcionamiento de los ejercicios antes de entregarlos.

## 4. Videos de YouTube

También utilicé videos de **YouTube** como material complementario, especialmente para aprender sobre **GitHub** y la forma correcta de realizar commits.

### Video utilizado

* Cómo trabajar con un repositorio.
* Cómo realizar commits correctamente.
* Cómo organizar y subir los cambios realizados en los archivos.
